Foundation

Elevation

12L is mostly flat: hairline borders on paper. Shadows are reserved for things that float above the page — menus, toasts, dialogs and sheets.

Tokens: tokens/tokens.css

Overview

Listing cards have no shadow and no border; the photo is the card. Panels and cards sit on a 1px --color-border-default edge. Shadows start at level 3 for anything that floats.

Surface hierarchy

Backgrounds encode height as well as shadows do. From low to high:

Sunken: wells, table headers, threads
Surface: cards, panels, inputs
Raised: dialogs, menus, popovers

Raised: dialogs, menus, popovers

Elevation in the dark theme

Shadows barely show on ink, so the dark theme raises surfaces in lightness (ink-950 canvas, ink-900 surface, ink-850 raised) and uses stronger, pure-black shadows (50-70% opacity) at every level.

Z-order

LayerTokenValueUsed by
base--z-basePage content
raised--z-raisedPressed segment over neighbours
sticky--z-stickyTop bar, buy bar, sticky form actions
dropdown--z-dropdownMenus
overlay--z-overlayModal backdrop
modal--z-modalDialogs, drawers, menu sheet
popover--z-popoverPopovers opened from a dialog
toast--z-toastToasts, cookie consent
tooltip--z-tooltipTooltips, skip link

Components never set a raw z-index. Mock chrome sits above everything at calc(var(--z-tooltip) + 10); it is not part of the product.

Usage

  • Don't add shadows to listing cards or list rows; they are flat by design.
  • A floating element always gets a shadow and a raised surface, so it separates in both themes.
  • Only one modal layer at a time; a dialog never opens another dialog.
