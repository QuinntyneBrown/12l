Foundation

Typography

Black-weight Archivo headings, tightly tracked like the logo's numerals, over Inter for everything people read and type. Nine sizes, twelve roles.

Tokens: tokens/tokens.css

Overview

Two families. Archivo (display) at black and bold weights for display, headings and prices: heavy, tight, confident, like the 12 in the logo. Inter (sans) for body, labels and inputs. A monospace stack is reserved for order and listing references.

Components set type with role shorthands (font: var(--text-label)) rather than individual properties, so a change of scale happens in one place.

Fallbacks are system fonts, so pages render immediately while web fonts load.

Roles

Each role is a font shorthand. Display, h1 and h2 add --letter-spacing-display; overlines add --letter-spacing-wide and uppercase.

  • --line-height-tight (1.2) for h2; display and h1 go tighter still inside their role (1.02 and 1.08).
  • --line-height-snug (1.3) for h3-h4.
  • --line-height-normal (1.5) for body, labels and captions.
  • --line-height-relaxed (1.65) for addresses and long-form legal pages.

Measure and numbers

  • Paragraphs are capped at --layout-measure (65ch). Empty-state text is capped at 36ch.
  • Headings use text-wrap: balance; paragraphs use text-wrap: pretty.
  • Prices, totals, counters, timers and table numbers use font-variant-numeric: tabular-nums (.num, .price) so columns align and timers don't jitter.
  • Listing titles truncate to one line with an ellipsis on cards; the full title is on the detail page.

Usage

  • One h1 per page. Dialog titles use the h3 role even though they are <h2> elements.
  • Overlines (uppercase) are for short labels only: brand names on cards, filter group legends, badges. Never a sentence.
  • Responsive type: below 640px the display role drops to --font-size-4xl and h1 to --font-size-3xl; everything else keeps its size.
  • Do not set font-size or font-weight ad hoc; pick a role. Buttons adjust size with .btn--sm/lg.

Accessibility

  • Text resizes to 200% without loss: sizes are in rem and containers wrap (1.4.4).
  • Text spacing overrides (line height 1.5, paragraph spacing 2em, letter spacing 0.12em) do not clip content (1.4.12): no fixed heights on text containers.
  • Muted and subtle text pass 4.5:1 on canvas, surface and sunken backgrounds in both themes; see color.
  • Uppercase is applied with CSS, so screen readers read the words, not letters.
