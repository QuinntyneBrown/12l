Foundation

Spacing

A 4px scale from 2px to 96px. Small steps inside components, large steps between them, and lots of white space around everything.

Tokens: tokens/tokens.css
  • Overview
  • Scale

Overview

Every margin, padding and gap is a --space-* token; the number is the multiple of 4px (--space-6 is 24px). The mocks used the scale everywhere except a few hairline nudges, which are documented below.

Inside and between

WhereSpaceExample
Icon to label--space-1–--space-2Button icons, status dots
Label to control, control to help--space-1Form field parts
Between inline items--space-2–--space-3Chips, button rows, cluster
Inside compact components--space-3–--space-4Alerts, toasts, list rows, table cells
Inside cards, panels, dialogs--space-6 (--space-8 panels from 768px)Cards, dialog header/body/footer
Between fields in a form--space-6Form sections and rows
Between sections--space-8–--space-12Page sections, profile head
Page rhythm--space-16–--space-24Hero, bottom of page, above the footer

Rule: components use --space-6 or less inside; layout uses --space-6 or more between. Listing grids use a larger row gap than column gap (32/16px on phones, 40/24px from 768px) so each card's text reads as belonging to its photo.

Usage

  • Use stack (.stack, --sm, --lg) and cluster (.cluster) for gaps instead of margins on children. See layout primitives.
  • Hairline offsets (1-2px) that align a glyph or border are allowed inside component CSS; they are not spacing and do not get tokens.
  • Don't invent half steps. If 12px is too tight and 16px too loose, the layout needs a different structure, not 14px.
