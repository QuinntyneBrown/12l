How to use

  1. Link tokens/tokens.css then assets/components.css.
  2. Use the documented classes and attributes; never restyle a component locally.
  3. Consume tokens/tokens.json (DTCG) for native or design tooling.
  4. In the Angular workspace the components library owns these styles under projects/components/src/styles/.
