Pattern

Data tables and lists

Members see lists of things they recognise by photo, so 12L uses rows with thumbnails; administrators compare records, so they get tables.

Overview

Most collections in 12L are lists of item rows (thumbnail, title, meta, price, status): purchases, sales, my listings, the moderation queue. Only the audit log and the size rules are true tables, because their rows are compared column by column. The catalog itself is a grid of listing cards.

When to use what

DataUseExample
Items a member recognises visuallyOrder list / item rows with thumbnailsPurchases, Sales, My listings
Things to browse and compare by eyeListing gridCatalog
Settings and preferencesSettings list (title, meta, control)Settings, Emails
Records compared across columnsTable with caption and scoped headersAudit log
Work to triageQueue list with type, age and statusModeration queue

States

  • Loading: skeleton rows in the list’s shape, container aria-busy (sales/loading).
  • Empty and error: see empty and error states.
  • Filtered: chips above the list show active filters, each removable; the count updates (my-listings/filtered).
  • No results: compact empty state with Clear filters (audit-log/no-results).
  • Hover: the row title underlines; tables tint the row with --color-bg-subtle.
  • More: the catalog uses Load more with a count (Showing 24 of 61) rather than numbered pages; numbered pagination is reserved for admin tables.

Responsive behaviour

  • Item rows never become tables: on phones the end column (price and status) stacks under the price.
  • Tables keep their columns and scroll inside .table-wrap; the first column carries the row’s identity.
  • The listing grid is 2 columns on phones, 3 from 768px, 4 from 1024px (3 beside the filters, 4 again from 1280px).
  • Toolbars (search, sort, filter button) wrap; the filter button only shows below 1024px.

Accessibility

  • Lists are <ul>; a clickable row contains exactly one link, and its accessible name is the row text.
  • Tables have a <caption> (visually hidden when the page heading already says it) and scope on headers; sortable headers use aria-sort on a button.
  • Status never relies on colour: the label is always text.
  • Thumbnails in rows have empty alt because the title next to them names the item.
  • Load more keeps focus on the button and announces the new count through the status region.

Content

  • Row titles are the item title; meta is Brand · Men’s US 12 or Order 12L-48213 · Shipped Thu 22 Oct.
  • Dates are short and absolute in lists (Fri 30 Oct), relative only for very recent events (2 hours ago).
  • Column headers are nouns in sentence case: When, Administrator, Action, Target.
