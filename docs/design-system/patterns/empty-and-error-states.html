Pattern

Empty and error states

When there is nothing to show, say why in one line and offer the one action that fixes it. When something broke, say what is safe and give a reference.

WCAG 2.2 AA

Overview

All four empty states and every error state use the empty state component (icon, title, one sentence, one action) or, for whole pages, the error page layout. They keep the page shell (top bar, account tabs, filters) so the member can still go somewhere else.

When to use what

SituationVariantExample
Nothing exists yetFirst-run: neutral icon, encouraging line, primary action that createsNothing bought yet. Everything in the catalog already fits. · Browse the catalog
Filters or search hide everythingNo results (.empty--compact): suggest loosening, action clearsNo items match. Try fewer filters or a different word. · Clear search and filters
The list failed to loadError as empty (.empty--error): danger icon, reference, Try againCouldn’t load purchases. Ref 51ce-0a92 · Try again
Work is donePositive empty: check iconQueue clear. New reports and order problems land here.
The whole page is goneerror page: 404, 403, 500, offline, maintenancePage not found, You can’t view this page

Responsive behaviour

  • Empty states centre in the space the content would have used; on phones they keep 48px of vertical padding, compact ones 32px.
  • Actions wrap and centre; the primary comes first.
  • Full error pages align left with a large code (404 with the red L treatment) and stack their actions on phones.

Accessibility

  • The empty-state title is a real heading at the right level for its place (h2 for a page body, h3 inside a section).
  • The icon is decorative (aria-hidden); the title carries the meaning.
  • When an error replaces a list after a retry, focus stays on the Try again button and the new state is announced through the page’s status region.
  • Reference codes are text, selectable and copyable, in the mono face.

Content

  • Empty formula: title states the fact (No sales yet), one line says what happens next or why it is fine (Sold items show up here with what to do next.), one action.
  • No-results formula: No items match + how to widen + Clear search and filters.
  • Error formula: Couldn’t load {thing} + Something went wrong on our side. + Ref xxxx-xxxx + Try again. Never blame the member for a server failure.
  • Titles are short and sentence case; no exclamation marks, no jokes in errors.
