Component · Navigation

Top bar

The sticky header on every member screen: menu button, the 12L logo, the four category links, search, Sell and the member's avatar.

Overview

The top bar is the only global navigation. It stays on screen while the member scrolls (sticky, --z-sticky) so search and Sell are always one tap away. The page itself provides the rest: account screens add tabs, listing detail adds a breadcrumb. Auth screens (sign in, register) drop the top bar for a centred logo.

  • Member: categories, search, Sell as a nav link with a plus icon, the avatar linking to the account.
  • Guest: the same, with Sell as a ghost button and Sign in as a secondary button.
  • Admin: logo, a red Admin tag, Queue and Audit log, and the administrator's initials. No search, no Sell.
  • Compact (below 768px): a menu button opens the full-screen menu sheet (drawer); search collapses to an icon button.

Anatomy

  1. Menu buttonGhost icon button, aria-expanded, visible below 768px only.
  2. LogoLinks to the catalog; aria-label="12L home"; 26px tall.
  3. Primary navNav links, 64px tall, the current one marked by a 3px signal-red bar.
  4. SearchSearch field from 1024px; an icon button below.
  5. ActionsSell link and avatar (member) or Sell + Sign in (guest).

Responsive behaviour

  • Below 768px: menu button, logo, spacer, search icon button and avatar. The category links and Sell move into the menu sheet.
  • 768px–1023px: category links and Sell appear; search is still an icon button that opens the catalog search state.
  • 1024px and up: the search field appears (max 22rem) and the search icon button hides.
  • Height stays 64px; horizontal padding follows --layout-margin (16 / 32 / 48px).

Theming

The bar is --color-bg-surface with a hairline --color-border-default bottom edge, so in dark it reads as a raised ink-900 strip over the ink-950 canvas. Nav links use --color-fg-muted and turn --color-fg-default on hover and when current; the current bar is --color-brand in both themes. The admin tag is --color-brand with --color-fg-on-brand.

Accessibility

Role and pattern

A <header> landmark containing a <nav aria-label="Primary"> of plain links (not an APG menubar), a role="search" form, and a disclosure button for the mobile menu (aria-expanded, aria-controls="menu").

Keyboard

KeyAction
TabMoves through menu button, logo, category links, search, Sell, avatar in that order.
EnterFollows a link; on the menu button opens the menu sheet and moves focus to its close button.
EscCloses the menu sheet and returns focus to the menu button.

Focus

The shared focus ring; nav links are 44px+ tall so the ring never clips. The skip link precedes the bar so keyboard users can jump straight to #main.

Labelling

Icon-only controls carry labels: Open menu, Search, Your account, Marcus Bell. The search input has a visually hidden Search 12L label. The current category is announced through aria-current="page", not colour alone.

Motion

Link colour and background change over --duration-fast. The bar itself never animates or hides on scroll.

Touch

Nav links are --layout-topbar-height (64px) tall; icon buttons 40px; the avatar 32px with 8px around it.

Content

  • Category names are single nouns in title case as they appear in the catalog: Shoes, Tops, Outerwear, Bottoms.
  • Sell, never Create listing or Post.
  • Guest call to action is Sign in; registration is offered from the sign-in page.
  • The account link's label names the member: Your account, Marcus Bell.
