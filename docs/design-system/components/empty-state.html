Empty state

What a list or area shows when it has nothing in it, nothing matches, or it could not load: an icon, a title, one sentence and one way forward.

WCAG 2.2 AAStatus: stableCompact and full

Overview

Use an empty state in place of a list, grid or table. It explains why the area is empty and offers the one action that fills it. Use an error page when the whole page failed, and an alert when content exists but something about it is wrong. Formulas for the copy are in empty and error states.

  • First run: Nothing bought yet · Everything in the catalog already fits. · Browse the catalog.
  • No results (compact): No items match · Try fewer filters or a different word. · Clear search and filters.
  • Error (.empty--error): Couldn’t load purchases · Ref 51ce-0a92 · Try again.
  • Done: Queue clear · New reports and order problems land here.

Anatomy

  1. Icon tile64px square, --color-accent-subtle with an accent icon; danger-tinted for errors.
  2. Title--text-h3, a heading at the right level for the page.
  3. TextOne sentence, max 36ch, muted.
  4. ActionsOne primary action; an optional secondary link.

Responsive behaviour

  • Centred at every width; text wraps at 36ch.
  • Actions wrap and centre; on phones the primary action stays inline-size (not block) because the empty state is not a form.
  • Beside the catalog filters (from 1024px) use the compact size so the filters stay the visual anchor.

Theming

Reads --color-accent-subtle / --color-fg-accent for the icon tile and --color-danger-bg / --color-danger-icon for the error tile. No component tokens.

Accessibility

Role and pattern

Plain content in place of the list. The title is a real heading (h2 on a page whose list is the main content, h3 inside a section). When a filter change produces no results, announce the result count through the page's role="status" region (0 items).

Content

  • Title says what is missing in member words: Nothing bought yet, No sales yet, No items match.
  • Text is one sentence that explains or encourages, with a little 12L voice: Everything in the catalog already fits.
  • Action is the verb that fixes it: Sell an item, Clear search and filters, Try again.
  • Errors: Couldn’t load {thing} + reference. Never No data.
