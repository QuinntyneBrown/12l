Component · Containers and overlays

Card

A bordered surface that groups related content: the order summary panel, the account stats, a payout account. 12L cards are square-cornered and mostly flat.

Overview

12L leans on white space and hairlines rather than boxes, so most content sits straight on the canvas. Use a container only when content is a unit the member acts on as a whole:

  • Panel (.panel): the workhorse. Order and checkout summaries, account overview stats, the sell success summary. No shadow, no radius.
  • Sunken panel (.panel--sunken): a quieter well for a prompt inside a page, such as How was jaybird? on a completed order.
  • Card (.card): a raised unit with optional header and footer, for settings blocks and admin report cards. 4px radius and --shadow-1.
  • Interactive: when the whole container is a link (account stats, category tiles), the container is the <a> and gets hover and focus states.
  • Well (.well): rounded sunken area for code or fine print.

Listings are not cards: they are listing cards, photo first, no border.

Anatomy

  1. Header.card__header: title (h4) and an optional status or action.
  2. Header asideStatus, badge or ghost button, top-aligned.
  3. BodyAny content; 24px padding all round.
  4. Footer.card__footer: hairline top edge, actions right-aligned.

Responsive behaviour

  • Panels stack full width below 1024px; on order and checkout pages they become the right column (2fr of a 3fr/2fr split) from 1024px.
  • Panel padding grows from 24px to 32px at 768px.
  • Category tiles are 2-up below 768px, 4-up above.
  • Never nest a card inside a card; use a divider or a sunken panel inside instead.

Theming

Containers read --color-bg-surface and --color-border-default. In dark the surface is ink-900 on an ink-950 canvas, so a panel still reads as raised; sunken panels drop to ink-1000. Cards expose --card-bg, --card-border, --card-shadow and --card-padding.

.card--flat { --card-shadow: none; }  /* a card with no lift, e.g. inside a dialog */

Accessibility

Role and pattern

A plain container: <div>, <section> with a heading, <article> for self-contained items, or <aside aria-label="Order summary"> for complementary panels. A clickable container is a single <a> with all content inside; never a div with a click handler or a link nested in a link.

Keyboard

KeyAction
TabInteractive containers are one tab stop; other containers are skipped, their own controls are reached in order.
EnterFollows an interactive container's link.

Focus

Interactive containers show the shared ring around the whole container.

Labelling

Give section panels a heading or an aria-label (Order summary). A stat link's name is its content: 3 Active listings.

Motion

Interactive cards raise to --shadow-2 and lift 1px over --duration-fast; removed under reduced motion.

Touch

Interactive containers are far larger than 44px; keep only one target inside them.

Content

  • Panel titles are short labels in sentence case: Order summary, Ship to.
  • Stat labels are plural nouns under the number: Active listings, Completed sales.
