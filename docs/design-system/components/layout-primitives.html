Layout primitives

Container, page, stack, cluster, grid and split: the six classes every 12L screen is laid out with, driven by the layout tokens.

Overview

Pages compose these primitives instead of writing layout CSS. Their spacing comes from --layout-margin, --layout-gutter, --layout-columns and the spacing scale, so every screen changes together at the breakpoints in layout.

  • Container centres content at --layout-container-max (1216px) with --layout-margin on each side.
  • Page adds the 64px bottom space; .page--narrow (40rem) for confirmations and .page--form (44rem) for the sell and profile forms.
  • Stack is a vertical flow with one gap (16px; 8px --sm; 32px --lg).
  • Cluster is a wrapping row (12px gap) for buttons, chips and inline facts.
  • Grid is the column grid (4 / 8 / 12 columns); .grid--auto fits 18rem cards.
  • Split is the detail layout: one column, then 3fr / 2fr from 1024px (order, sale and checkout pages).

Anatomy

  1. Margin--layout-margin: 16 / 32 / 48px.
  2. Column--layout-columns: 4 / 8 / 12.
  3. Gutter--layout-gutter: 16 / 24 / 32px.

States

Layout primitives are static; they have no interactive states.

Responsive behaviour

BreakpointColumnsGutterMargin
< 768px416px16px
768–1023px824px32px
≥ 1024px1232px48px
  • Split, catalog layout and listing detail switch to two columns at 1024px (the system's lg breakpoint).
  • The listing grid is 2-up, 3-up from 768px, 4-up from 1024px; with the filters column it is 3-up at 1024px and 4-up from 1280px.
  • Below 640px the listing-detail gallery bleeds to the screen edge (negative --layout-margin).

Accessibility

Role and pattern

Presentational: plain <div>s that never change reading order. Visual order always matches DOM order (no order or reversed flex), so focus moves the way the page reads (1.3.2, 2.4.3).

Keyboard

Not interactive.

Focus

Not applicable.

Labelling

Not applicable; use landmarks (main, aside aria-label) inside the layout for structure.

Contrast

Text on canvas

Motion

None.

Touch

Reflows to one column at 320px without horizontal scrolling (1.4.10).

Content

Layout primitives hold no copy.
