Video player

A captioned video with native controls plus Play/Pause, Captions and a transcript link, and clear loading and error states.

WCAG 2.2 AAStatus: stableSince v1.0

Overview

A captioned video with native controls plus Play/Pause, Captions and a transcript link, and clear loading and error states. Used on the marketing page at /welcome.

Anatomy

  1. 16:9 ink frame with the video (MP4 then WebM sources, English captions track)
  2. State overlay: spinner while loading, message and Try again on error
  3. Controls: Play/Pause, Captions (toggle), Read the transcript

Variants

One variant, used inside the pitch video dialog.

The video didn’t load

Check your connection and try again, or read the transcript.

Read the transcript

Sizes

One size; it fills its container.

States

Loading (role=status spinner), playing (Pause), paused (Play), captions on (aria-pressed=true, track showing), error (role=alert, Try again; the transcript link stays).

Responsive behaviour

Fills its container at 16:9; controls wrap.

Theming

Frame is ink in both themes; controls use page tokens.

Accessibility

Never autoplays on load: playback starts only from a press. Space toggles while the video has focus, and Play/Pause is a native button. Captions are WebVTT; a plain-text transcript is always linked (WCAG 1.2.1, 1.2.2).

Content

Error copy says what happened and what to do; no codes.

Do and don’t

  • Do keep it on the marketing page.
  • Don’t reuse it for app screens, which use the page header and panels.

Tokens

--color-showcase-start, --color-fg-showcase, --color-fg-showcase-muted, --space-2, --space-3, --space-6, --text-h4.

Code

<tl-video-player label="12L in 30 seconds" [sources]="sources" captions="/media/12l-pitch.vtt" transcript="/media/12l-pitch.txt" poster="…" />
