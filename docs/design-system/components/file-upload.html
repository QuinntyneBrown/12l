File upload

The photo uploader on the sell form and problem reports: a grid of square tiles, the first is the cover, with an Add photos tile that opens the file picker or takes a drop.

Overview

Use the uploader for photos of an item: 1–8 on a listing, up to 4 on a problem report. The real control is a visually hidden <input type="file" multiple> inside the Add photos label; drag-and-drop and reordering are enhancements on top.

  • The first tile is the cover and carries a Cover badge.
  • Each tile has a labelled remove button (Remove photo 2).
  • Rejected files stay as a red tile naming the file and why, until removed.

Anatomy

  1. Cover badge.badge on the first photo.
  2. RemoveSmall icon button, surface background, top-right.
  3. Add tileDashed 1px --color-border-strong, camera icon, count 1 of 8.

Responsive behaviour

  • 3 columns with 8px gaps below 640px; 4 columns with 12px gaps from 640px.
  • On phones the file picker offers the camera directly (accept="image/*" types).
  • Reordering by drag has a keyboard alternative: Move earlier / Move later buttons in each tile's menu.

Theming

Add tile: --color-border-strong dashed edge, --color-fg-muted text; hover and dragging switch to --color-fg-default. Rejected tile: --color-danger-bg with --color-danger-fg. Photos keep their light studio backdrops in dark theme.

Accessibility

Role and pattern

The native file input is the control (inside the Add photos <label>); the list is role="list"; progress uses role="progressbar". Drop is an enhancement only.

Keyboard

KeyAction
TabReaches the Add photos tile (the hidden input) and each remove button.
Enter / SpaceOpens the file picker or removes a photo.

Focus

The ring is drawn on the add tile via :focus-within.

Labelling

Remove buttons name the photo. Errors (Add at least one photo. Photos must be 10 MB or smaller.) are linked to the input with aria-describedby; upload completion is announced in the form's live region.

Motion

Progress fill animates over --duration-slow; zeroed under reduced motion.

Touch

Tiles are at least 96px square; remove buttons are 32px.

Content

  • State the formats and limit once, in help: JPEG, PNG or WebP up to 10 MB.
  • Rejected tiles show the file name and size, so the member knows which photo failed.
  • Show the count against the limit: 3 of 8.
