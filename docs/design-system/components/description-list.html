Description list

Key–value pairs for one record: a listing's facts, a member's account details, an order's tracking number.

WCAG 2.2 AAStatus: stableNative <dl>

Overview

Use a description list when a record has a handful of named attributes that are read one by one. For many records with the same attributes use a table; for money that adds up use the order summary.

  • Facts (.facts): the listing detail block. Muted term column sized to its longest term, 12px × 32px gaps.
  • Dl (.dl): the generic two-column list for admin and account detail. Label-style terms.
  • Facts row (.facts-row): a single pair spread across the row between rules, for a value that must stand out, such as a tracking number.

Anatomy

  1. Term<dt>: --text-body-sm in --color-fg-muted, column as wide as the longest term.
  2. Description<dd>: body text in the default colour; may hold a link, a time or a status.

Sizes

Description lists take the type size of their context; spacing is fixed per variant.

States

Description lists are static. The only interactive content is a link inside a <dd>, which takes the link states.

Responsive behaviour

  • The two columns stay side by side down to 320px because terms are short (Size, Listed). A term longer than three words means the list is the wrong component.
  • Facts rows wrap the value under the term when they do not fit; long tracking numbers break anywhere (overflow-wrap: anywhere).
  • On listing detail the facts sit in the sticky info column from 1024px.

Theming

Terms read --color-fg-muted, values --color-fg-default, facts-row rules --color-border-default. No surface of its own.

Accessibility

Role and pattern

A native <dl> with <dt>/<dd> pairs. Screen readers announce description list, 4 items and pair each term with its value. A facts row is a plain two-span row because it holds one pair.

Keyboard

No keyboard interaction of its own; links inside values are in the normal tab order.

Focus

Links inside values show the standard ring.

Labelling

Terms label their values. External links add visually hidden text (opens USPS tracking) next to the external icon.

Content

  • Terms are one or two words, sentence case, no colon: Size, Member since.
  • Sizes are written in full in facts: Men's US 12; conditions use the listing scale: Used - Excellent.
  • Relative times (2 hours ago) carry an absolute datetime.
