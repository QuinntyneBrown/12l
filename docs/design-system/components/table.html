Table

Tables compare records across the same columns: the admin audit log, payout history, the accepted sizes in the marketplace rules.

WCAG 2.2 AAStatus: stableNative <table>

Overview

Use a table when people read across columns to compare values: when an action happened, who did it, to what and why. Use a list when each record is read on its own (orders, listings, reports), and a description list for one record's facts.

  • Default is the admin audit log: five text columns, newest first, sticky sunken header.
  • Row headers (<th scope="row">) name each row when the first column is the key, as in the rules page's category table.
  • Sortable columns put a button in the header and set aria-sort.
  • Selectable rows add a checkbox column and aria-selected; row actions sit in a last, unlabelled column.
  • 12L is mostly read on phones, so tables are reserved for admin and reference content. Member-facing collections are lists.

Anatomy

  1. Container.table-wrap: 1px --color-border-default, --radius-lg, surface background, horizontal scroll.
  2. Header cellSunken background, --text-label in muted ink, sticky to the top of the scroll area, never wraps.
  3. Body cell--text-body-sm, 12px × 16px padding, 1px divider between rows; numbers right-aligned with tabular figures.
  4. CaptionNames the table for screen readers; visually hidden when the page heading already says it.

Variants

Choose the smallest variant that does the job. Every variant keeps a real <caption> and scoped headers.

Responsive behaviour

  • The wrapper scrolls horizontally below the table's natural width; the page never scrolls sideways. Header cells never wrap, body cells do.
  • Below 640px keep at most four columns visible; move secondary columns (Administrator, Fee) into the row's detail page rather than squeezing them.
  • Member-facing records (orders, listings, payouts on phones) use a list instead of a table; the payout table is the desktop view.
  • Row actions are always visible on touch devices (@media (hover: none)), because hover never happens there.

Theming

The table reads --color-bg-surface for cells, --color-bg-surface-sunken for headers, --color-border-default for rules, --color-bg-subtle for row hover and --color-accent-subtle for selected rows. In dark the surface is --palette-ink-900 and the header drops to the sunken ink, so the header still reads as a separate band.

/* An embedded table on a sunken panel keeps its own surface: */
.panel--sunken .table-wrap { background: var(--color-bg-surface); }

Accessibility

Role and pattern

A native <table> with <caption>, <thead> and scope on every header cell. No grid role: the table is read, not navigated cell by cell. Sortable headers contain a real <button> and the <th> carries aria-sort.

Keyboard

KeyAction
TabMoves through the interactive things in the table only: sort buttons, row checkboxes, links and row actions, in reading order.
Enter / SpaceOn a sort button, toggles ascending and descending; on a checkbox, selects the row.
Screen-reader table keysMove by cell and announce the column and row headers, because every header has a scope.

Focus

Each control inside a row shows the standard ring. Row actions that are hidden until hover become visible on :focus-within, so keyboard users never tab to an invisible button.

Labelling

The caption names the table (Administrator actions, newest first). The checkbox and actions columns have visually hidden header text. Each row checkbox and action button names its record: Select order 12L-48302, More actions for order 12L-48302.

Contrast

Header text on sunken
Cell text on surface
Cell text on hovered row
Cell text on selected row

Motion

Row actions fade in over --duration-fast; nothing else moves. Reduced motion removes the fade.

Touch

Sort buttons and row checkboxes keep a 24px minimum target; row action buttons are 32px (.btn--sm) with 8px around them.

Content

  • Column headers are nouns in sentence case: Time (ET), Action, You earn. Put the unit or time zone in the header, not in every cell.
  • Dates follow the 12L format: Today 11:20, Sat 24 Oct 16:18. Money always has cents in tables: $40.50.
  • IDs (L-20802, 12L-48302, R-3290) are shown exactly, in code style, never shortened.
  • Reasons are one sentence fragment without a full stop: Photos match the listing.
  • Empty cells show an em dash (—), never blank and never N/A.
