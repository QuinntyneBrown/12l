Avatar

A member's initials in a small square block: next to a seller's name, in the top bar as the account link, large on profiles.

WCAG 2.2 AAStatus: stableInitials only

Overview

12L has no profile photos: members are identified by handle, and the avatar is their initials on --color-accent-subtle. Square with 2px corners, like every other 12L block.

  • Decorative next to a name (seller block, reviews, admin pages): aria-hidden="true", because the name is right there.
  • Account link in the top bar: an <a> with aria-label="Your account, Marcus Bell".
  • Group: overlapping avatars with a +2 overflow block and one label for the group.
  • Status dot: a green dot for online now, always repeated in text nearby.

Anatomy

  1. InitialsTwo letters from the real name, --text-label scaled with the size.
  2. BlockSquare, --radius-sm, --color-accent-subtle background.

Responsive behaviour

  • The profile header avatar stays 96px; the header wraps the name and stats under it below 640px.
  • The top-bar account avatar is 32px at every width and sits last in the actions.

Theming

Background --color-accent-subtle, initials --color-fg-accent. In dark both flip to ink-800 with paper initials. Groups ring each avatar with --color-bg-surface so overlaps stay readable.

.seller .avatar { --color-accent-subtle: var(--color-bg-subtle); } /* quieter block on a busy surface */

Accessibility

Role and pattern

A <span> with aria-hidden="true" when a name is adjacent; an <a> with an aria-label when it is the only link to the account; role="img" with a label on a group.

Keyboard

KeyAction
TabReaches the account avatar link; decorative avatars are skipped.

Focus

The standard focus ring around the 32px block.

Labelling

Account link: Your account, Marcus Bell. Groups: one label listing the names and the overflow count. Status dots are never the only signal.

Touch

Content

  • Initials come from the member's real name (MB for Marcus Bell), never from the handle; show the handle beside it.
  • Overflow says the exact count: +2.
