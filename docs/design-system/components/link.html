Link

Links take the member somewhere: to the terms, a seller's profile, a tracking page. They are ink and underlined, so they never rely on colour alone.

WCAG 2.2 AAStatus: stableNative <a href>

Overview

Use a link when activating it navigates: to another page, a section, a file or another site. If it changes something (saves, deletes, opens a dialog that acts), use a button. A link can look like a button when it is the primary way forward (Sell an item, Sign in); it stays an <a>.

  • Inline links sit in running text: I accept the terms and marketplace rules.
  • Standalone links (.link-standalone) stand on their own line with an optional icon: Back to sales, the seller name on a listing.
  • External links go off 12L (carrier tracking, the payment provider). They show the external icon and announce where they go.

Anatomy

  1. LabelSays where the link goes. Ink (--color-fg-link), --text-label when standalone.
  2. External icon (optional)16px, after the label, only for links that leave 12L.
  3. Underline1px, offset 0.15em; thickens to 2px on hover. It is how a link is recognised, so it is never removed in running text.

Responsive behaviour

  • Long links (tracking numbers, emails) break anywhere (overflow-wrap: anywhere) rather than overflowing at 320px.
  • Standalone links keep a 24px minimum height so they remain a target on touch screens.
  • Footer links wrap into rows with --space-2 by --space-6 gaps.

Theming

Links read --color-fg-link and --color-fg-link-hover. In 12L both themes keep links the same colour as body text (ink in light, paper in dark) and rely on the underline, matching the brand's ink-on-paper restraint. Signal red is never a link colour.

/* Links inside an inverse surface inherit the surface text colour */
.consent a, .toast a { color: inherit; }

Accessibility

Role and pattern

Native <a href>; no role needed. A disabled link has no href or carries aria-disabled="true" and is skipped by pointer events.

Keyboard

KeyAction
TabMoves focus to the link.
EnterFollows the link. (Space scrolls the page; links do not respond to it.)

Focus

The shared 2px ink ring with 2px offset on :focus-visible; links inside inverse surfaces switch the ring to --color-fg-inverse.

Labelling

The text says where it goes; never click here or read more on its own. External links add visually hidden text such as (opens USPS). A link that opens a new tab says so.

Motion

No animation; the underline thickness changes instantly.

Touch

Inline links rely on line height; standalone links are at least 24px tall (--target-min) and keep 8px from neighbouring targets.

Content

  • Name the destination: marketplace rules, marcus_12, Back to sales.
  • Link the meaningful words in a sentence, not the whole sentence.
  • Tracking numbers are links to the carrier, shown in tabular numerals.
  • Do not link the same destination twice in one paragraph.
