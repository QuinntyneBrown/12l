Checkbox

A square box for an independent yes/no: accepting terms, confirming the label shows US 12, picking any number of filters.

WCAG 2.2 AAStatus: stableNative checkbox

Overview

Use a checkbox for a choice that stands alone (I accept the terms) or for picking any number from a list (filters: Sneakers, Boots). For exactly one of several, use a radio group. For a setting that applies immediately, use a switch.

  • Square (--radius-xs is 0) like the logo; ink fill with a paper tick when checked.
  • Groups live in a <fieldset> with a <legend>; the whole label is the target.

Anatomy

  1. Box20px square, 1px --color-border-strong edge; checked fills with --color-accent and a --color-fg-on-accent tick.
  2. Label--text-body, wraps beside the box; clicking it toggles.

Sizes

One size: a 20px box with a row at least 24px tall (--target-min).

Both themes

Responsive behaviour

  • Labels wrap beside the box; the box stays top-aligned with the first line.
  • Filter groups sit in the sidebar from 1024px and in the filter sheet below it; same markup.

Theming

Reads --color-border-strong, --color-bg-surface, and when checked --color-accent with --color-fg-on-accent; in the dark theme the box fills paper with an ink tick.

Accessibility

Role and pattern

Native <input type="checkbox"> inside its <label>; groups in <fieldset>/<legend>. Mixed state uses the indeterminate property (exposed as mixed).

Keyboard

KeyAction
TabMoves to each checkbox.
SpaceToggles.

Focus

The ring is drawn around the box (2px, 2px offset).

Labelling

The label text is the name; errors are linked with aria-describedby and the group legend gives context.

Contrast

Box edge on page
Tick on fill
Checked fill on page
Invalid edge

Motion

Fill transitions over --duration-fast.

Touch

The whole label is the target; rows are at least 24px tall with 8px between them.

Content

  • Write the label as the statement being agreed to: I’m 18 or older.
  • Errors repeat what to tick: Accept the terms to continue.
  • Never pre-tick consent or marketing boxes.
