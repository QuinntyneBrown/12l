Skip link

The first thing a keyboard user reaches on every page: one link that jumps past the top bar to the main content.

Overview

Every 12L page, including auth and admin screens, starts with <a class="skip-link" href="#main">Skip to content</a>. It is off screen until it receives keyboard focus, then slides into the top-left corner above everything (--z-tooltip).

Anatomy

  1. LinkRaised surface, --shadow-3, 8px × 16px padding, appears at 16px from the top-left.

Variants

There is one skip link per page, always to #main.

Sizes

One size.

Responsive behaviour

  • Same on every breakpoint; it overlays the top bar rather than pushing it down.

Theming

--color-bg-surface-raised with --color-fg-default and --shadow-3, so it stands off the top bar in both themes.

Accessibility

Role and pattern

A same-page link to <main id="main">. The target needs no tabindex in modern browsers; focus and the reading position move to main.

Keyboard

KeyAction
TabFirst press on page load focuses and reveals it.
EnterMoves to the main content; the next Tab continues from there.

Focus

The shared ring plus the slide-in; the link is fully visible while focused (2.4.11 Focus not obscured).

Labelling

Visible text Skip to content.

Contrast

Link text on raised surface

Motion

Slides in over --duration-fast; instant under reduced motion.

Touch

Not used by touch; 40px tall when visible.

Content

  • Always Skip to content.
