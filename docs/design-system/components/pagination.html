Pagination

Moves through long result sets. The catalog uses Load more; numbered pagination is the core alternative for tables and the audit log.

Overview

Browsing listings is exploratory, so the catalog appends results with a Load more button and a count (Showing 14 of 1,284), keeping earlier items and the scroll position. Numbered pagination is for lists people search by position or come back to: admin queues, the audit log, long order histories. Never use infinite scroll: the footer must stay reachable.

See data tables and lists for which to choose.

Anatomy

  1. Previous / nextIcon links with aria-label; disabled at the ends.
  2. Current pageAccent-subtle fill and accent edge, aria-current="page".
  3. GapAn ellipsis hidden from assistive tech.

Responsive behaviour

  • Below 640px numbered pagination shows previous, current of total and next (2 of 12) instead of every number.
  • Load more is centred and full width below 640px.

Theming

Items are transparent with --color-fg-muted labels; hover uses --color-bg-subtle; the current page reuses the selected treatment (--color-accent-subtle fill, --color-accent edge).

Accessibility

Role and pattern

A <nav aria-label="Pagination"> with a list of links. Load more is a <button> described by Loads the next 24 items; after loading, focus moves to the first new item.

Keyboard

KeyAction
TabEach page link is a stop; disabled ends are skipped.
EnterGoes to the page / loads more.

Focus

Shared focus ring on the 32px item.

Labelling

Numbers get aria-label="Page 3"; arrows Previous page / Next page. The result count is plain text next to Load more and is updated through the catalog's polite live region.

Motion

None; new results appear without animation.

Touch

32px items with 4px gaps meet the 24px minimum; Load more is a 40px button.

Content

  • Count format: Showing 14 of 1,284, with thousands separators.
  • Button label: Load more, never See more results….
  • Simple pager labels for time-ordered lists: Newer / Older.
