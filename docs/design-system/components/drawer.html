Drawer and sheet

Panels that slide in from an edge: the full-screen menu sheet on phones, the filters sheet, and a side drawer for previews.

Overview

Sheets and drawers are dialogs that keep the page's context at the edge. 12L uses two:

  • Menu sheet (.menu-sheet): opened by the top bar's menu button below 768px. Full screen, categories in large type, account links in body type, Sign out at the bottom.
  • Filter sheet (.menu-sheet.filter-sheet): catalog filters below 1024px. Full screen on phones, a 24rem panel from the left from 768px, with Clear all and Show 41 results pinned at the bottom.
  • Drawer (.drawer): a 28rem side panel from the right (or left) for previews and secondary tasks. Core; no mock uses it yet.

Use a dialog for a decision; use a sheet when the content is navigation or a set of controls the member adjusts and applies.

Anatomy

  1. HeadTitle (or the logo) and the close button, 64px tall like the top bar.
  2. CloseGhost icon button.
  3. BodyScrolls; 32px vertical padding, groups 32px apart.
  4. FootPinned actions; 48px buttons that share the width.

Responsive behaviour

  • The menu sheet only exists below 768px; at 768px the top bar shows the links and the sheet closes if open.
  • The filter sheet becomes the sticky filters column at 1024px.
  • Sheet heads match --layout-topbar-height so the close button sits where the menu button was.

Theming

Sheets use --color-bg-canvas (they replace the page); drawers use --color-bg-surface-raised with --shadow-4. Dividers are --color-border-default.

Accessibility

Role and pattern

APG Dialog (modal) with role="dialog", aria-modal="true" and a label (a visually hidden Menu heading for the menu sheet). The opener has aria-expanded and aria-controls.

Keyboard

KeyAction
TabCycles inside the sheet.
EscCloses and returns focus to the opener.
EnterFollows a link or applies filters.

Focus

Menu sheet: initial focus on Close menu. Filter sheet: on the first filter. Focus returns to the menu or Filters button on close.

Labelling

Close buttons say what they close: Close menu, Close filters. The apply button includes the result count.

Contrast

Sheet link
Drawer text

Motion

Menu sheet fades in over --duration-base; filter sheet and drawer slide from their edge over --duration-slow. Instant under reduced motion.

Touch

Menu links are 56px tall rows; small links 44px; foot buttons 48px.

Content

  • Apply buttons state the outcome with the count: Show 41 results.
  • Reset is Clear all.
  • Menu categories match the top bar exactly.
