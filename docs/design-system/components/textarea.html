Textarea

A multi-line input for descriptions, review replies, report details and notes. Grows with its content and shows a counter when there is a limit.

WCAG 2.2 AAStatus: stableNative <textarea>

Overview

Use a textarea when the answer can run past one sentence: the listing description (2,000 characters), a review comment (500), a reply to a review, details for a report or a cancellation note. For one line, use a text field.

  • Minimum two rows; three for comments and replies, four for the listing description.
  • Resizable vertically only, and auto-growing where supported (field-sizing: content).
  • When there is a limit, a counter sits under the field (58 / 500) and turns into an error past the limit.

Anatomy

  1. LabelVisible, --text-label.
  2. ControlAt least 2 rows (100px at --control-height-md × 2.5), --text-body, vertical resize.
  3. HelpRules that apply before typing.
  4. Counter--text-caption, right-aligned, --color-fg-subtle.

Sizes

Textareas have one width (their column) and set height in rows: 2 for notes, 3 for comments, 4 for descriptions.

Both themes

Responsive behaviour

  • Full width of its column at every size.
  • On phones keep the visible rows small (2–3) so the keyboard does not hide the submit button; auto-grow takes over as the member types.

Theming

Same component tokens as the text field (--field-*); the counter reads --color-fg-subtle.

Accessibility

Role and pattern

Native <textarea> with <label for>; help, error and counter are linked via aria-describedby. The counter is not a live region on every keystroke; it is announced when the limit is crossed through the error.

Keyboard

KeyAction
TabMoves into and out of the textarea.
EnterNew line (it never submits).
Ctrl+EnterNot bound; forms submit with their button.

Focus

Same 2px ring at 0 offset as text fields.

Labelling

Visible label; limits stated in help or counter before the member types.

Contrast

Text on field
Counter on page
Edge on page

Motion

None beyond the edge colour transition.

Touch

Minimum 80px tall; the resize handle is optional, not the only way to see content (it scrolls).

Content

  • Say who will read it: Visible to the buyer and to 12L.
  • State the limit as numbers with a thousands separator: 76 / 2,000.
  • Prompt with a label, not a question in the placeholder.
