Component · 12L brand

Photo

The product photo frame: a 4:5 studio backdrop in one of six warm tones, the item centred, the size tag in the corner and a stamp when it is reserved or sold.

WCAG 2.2 AAStatus: stable.photo4:5 and 1:1

Overview

Every listing image sits in .photo: square corners, a light studio backdrop that stays light in dark mode (real photos would), and an aspect ratio that never shifts while the image loads. Cards use the 4:5 portrait frame; thumbnails in order rows, the uploader and the gallery strip use the square frame. Missing photos (a draft without images) show an icon on subtle instead of a broken image.

  • Tone (.photo--1 to --6) is assigned per listing so a grid reads as a set of different products, not one flat block.
  • Stamp (Reserved, Sold) sits top left; the size tag sits bottom left.
  • Thumb wraps a square photo at 56px (.thumb) or 80px (.thumb--lg).

Anatomy

  1. Stamp (optional)Reserved on paper, Sold on ink; --text-overline, --shadow-1.
  2. ImageCentred at 78% width; alt names brand and item.
  3. Size tagsize tag, pinned bottom left.
  4. Frameaspect-ratio: 4 / 5, backdrop --color-photo-bg-N, square corners, overflow hidden.

Backdrops do not darken in dark mode: the photo is content, not chrome.

Responsive behaviour

  • The frame is fluid; the aspect ratio holds at every width, so grids never jump while images load (width/height attributes are still set).
  • On listing detail below 640px the main photo bleeds to the screen edges; from 640px it sits inside the margins.
  • Images load lazily (loading="lazy") except the first row of the catalog and the gallery's main photo.

Theming

Backdrops read --color-photo-bg-1..6, which alias --palette-photo-1..6 in both themes. Stamps read --color-stamp-bg/-fg (paper/ink); Sold swaps them. To add a tone, add a primitive and a semantic token, then a .photo--7 modifier.

Accessibility

Role and pattern

A <div class="photo"> around a real <img>. The stamp and tag are text, so they are read in order after the image.

Keyboard

Not focusable on its own; it is reached through its card, row or gallery button.

Focus

The containing card or gallery button shows the ring around the frame.

Labelling

alt names the item: Nike Air Max 90, white; gallery photos add the position: Photo 2 of 5, Nike Air Max 90, white. Thumbnails next to the item title use alt="" so the name is not read twice. The no-photo frame is role="img" with No photos yet.

Motion

In listing cards the image scales to 104% over --duration-slow on hover; reduced motion removes the transition.

Touch

Not a target on its own.

Content

  • Alt text: brand, then the listing title as the seller wrote it. No photo of, no colours the title does not mention.
  • Stamps are one word: Reserved, Sold. No other stamps (no New, no Sale).
  • Never overlay prices or text on the photo; they go below in the card.
