Breadcrumb

Shows where a listing or order sits and lets the member step back up: Shop / Shoes / Sneakers.

WCAG 2.2 AAStatus: stable<nav aria-label="Breadcrumb">

Overview

Use a breadcrumb on detail pages that sit under a hierarchy: listing detail (category path), order and sale detail (Purchases / Order 12L-48213), admin report and problem detail. Do not use it on top-level pages or as the only way back from a dialog.

  • Category path: Shop / Shoes / Sneakers on listing detail.
  • Back to list: two levels, the list and the item: Sales / Order 12L-48302.

Anatomy

  1. Ancestor linkMuted, no underline until hover.
  2. SeparatorA slash drawn by CSS; not read out.
  3. Current pageDefault colour, medium weight, not a link.

Responsive behaviour

  • The list wraps onto a second line rather than truncating.
  • Below 640px, paths deeper than three levels collapse to the parent only, shown with a back arrow: ← Shoes.

Theming

Ancestors --color-fg-muted, separators --color-fg-subtle, current --color-fg-default. No component tokens.

Accessibility

Role and pattern

APG Breadcrumb: <nav aria-label="Breadcrumb"> around an ordered list; the last item has aria-current="page". Separators are CSS generated content so they are not announced.

Keyboard

KeyAction
TabEach ancestor link is a stop; the current item is not focusable.
EnterFollows the link.

Focus

Shared focus ring.

Labelling

One breadcrumb per page, labelled Breadcrumb.

Contrast

Ancestor link
Current

Motion

None.

Touch

Links are inline text; the row has 8px gaps. On phones the collapsed back link is 44px tall.

Content

  • Use the same names as the destination pages' headings.
  • The current item is the page's own name, short: the order number, not the item title.
