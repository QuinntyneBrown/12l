Component · 12L brand

Logo

The 12L wordmark: two heavy ink numerals and a signal-red L with one 45° cut. It links home and is the only place the red appears at full size.

Overview

The logo identifies 12L and takes the member home. In the product it is always inline SVG inside <a class="logo">, so the ink numerals follow currentColor (ink in light, paper in dark) while the L stays --color-brand. Static files in docs/design-system/assets/ (logo.svg, logo-dark.svg, PNG and favicon) are for email, social and app icons where CSS cannot reach.

  • Top bar (medium, 26px tall) on every member and admin page.
  • Auth (large, 44px) centred above sign-in, register and password screens.
  • Footer (small, 18px) beside the legal links.
  • The red L is never used as a general accent colour; for indicators (current page, current order step) use --color-brand as a 3px bar, not as text.

Anatomy

  1. 1Ink numeral; .logo__ink, fills with currentColor.
  2. 2Ink numeral with the diagonal; same fill.
  3. LSignal red --color-brand; .logo__l. Never recoloured.
  4. The cutOne 45° chamfer at the bottom right of the L. It is the source of the size tag's and confirmation mark's chamfer.

One mark, rendered two ways. Inline SVG in the product (it themes itself); static files outside it.

Below 18px the numerals' counters close up; use the app icon instead. Clear space on every side is at least the width of the L's stem (about a quarter of the height): nothing, not even the admin tag, sits closer.

States

The logo is a link. It has no hover colour change (the brand mark does not flicker); the focus ring is the shared ring.

Responsive behaviour

  • The top-bar logo stays medium at every width; on phones it sits after the menu button, on tablet and up before the category links.
  • Auth screens keep the large logo at every width and centre it above the card.
  • The admin shell shows the red Admin tag after the logo with --space-3 between them, never touching the L.

Theming

Two colours, two mechanisms: the numerals use currentColor (so --color-fg-default in both themes), and the L uses --color-brand, which is --palette-signal-500 in light and dark. On ink the red keeps 3.3:1 against the canvas.

.logo svg .logo__ink { fill: currentColor; }
.logo svg .logo__l   { fill: var(--color-brand); }

Accessibility

Role and pattern

A link (<a class="logo" href="/">) with aria-label="12L home"; the SVG inside is aria-hidden and focusable="false". A static <img> logo has alt="12L".

Keyboard

KeyAction
TabReaches the logo after the skip link and menu button.
EnterGoes to the catalog (members) or the moderation queue (admin).

Focus

Shared 2px ring with 2px offset around the whole mark.

Labelling

12L home in the top bar; the footer logo has the same name. Never logo or image.

Contrast

Numerals on canvas
Red L on canvas
Red L on top bar

Motion

None. The mark never animates.

Touch

The medium logo link is 26px tall inside a 64px top bar; its hit area is padded to the bar height so it clears the 44px target.

Content

  • Write the name as 12L: digits then a capital L, no space, never 12l, Twelve L or 12-L.
  • In sentences the name is plain text, not the logo.
  • Alt text and labels say 12L or 12L home; nothing about colours or shapes.
