Skeleton

Grey placeholders in the exact shape of the content that is loading, so the page does not jump when the data arrives.

WCAG 2.2 AAStatus: stablearia-hidden shapes

Overview

Every page that fetches data shows skeletons on first load, in the final layout: the catalog shows eight skeleton listing cards in the real grid with the filters already usable; account lists show skeleton rows. Use a spinner only when the shape of the result is unknown. Never show skeletons for more than a few seconds; after that switch to an error (empty state).

Anatomy

  1. Photo.skeleton--photo: 4:5, square corners like real photos.
  2. BrandText line at 40% width.
  3. TitleText line at 85%.
  4. Condition and priceText line at 55%.

Variants

Primitives: title, text (last line 60%), circle, rect.

Composed

Listing cards (catalog/loading) and list rows (purchases, sales, queue).

Sizes

Skeletons take the size of the content they stand in for; text lines follow the font size of their parent.

States

ShapeShimmerReduced motion
Text
Photo

Both themes

When data arrives the skeletons are replaced in one swap, not card by card, and aria-busy is removed so the new content is read.

Responsive behaviour

  • Skeleton grids use the real grid classes (.listing-grid), so they get 2, 3 and 4 columns at the real breakpoints.
  • Show as many skeleton items as fit the first screen: 8 cards on the catalog, 4 rows in lists.

Theming

The shimmer is a gradient between --color-bg-subtle and --color-bg-subtle-hover; in dark those are ink-800 and ink-700, so skeletons sit just above the surface.

Accessibility

Role and pattern

Every skeleton shape is aria-hidden="true" (or inside an aria-hidden card). The container that is loading gets aria-busy="true" and an aria-label (Loading listings).

Keyboard

Nothing focusable inside a skeleton. Controls that work without data (filters, search) stay usable.

Focus

Unchanged.

Labelling

The container's aria-label is the only announcement.

Contrast

Skeleton on surface (decorative)

Motion

Shimmer sweeps over --duration-cycle; under reduced motion it is static.

Touch

Not interactive.

Content

Skeletons have no text. Do not write Loading… over them.
