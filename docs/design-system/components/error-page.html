Error page

When a whole page cannot be shown: a big 12L-style code, a plain title, what is safe, and one way back. The shell stays so the member is never stranded.

WCAG 2.2 AAStatus: stableKeeps the shell

Overview

Error pages replace the main content, not the whole document: the top bar, footer and search stay so the member can carry on. The status code is set in the display face with the middle digit in signal red, echoing the red L. For a failed list use an empty state; for a failed action an alert or toast.

  • 404 Page not found, and the listing-specific This item isn’t available.
  • 403 You can’t open this / Admins only.
  • 500 Something went wrong with Try again and the reference.
  • Offline You’re offline, with an icon instead of a code.
  • Maintenance Back at 3:00 AM ET, served statically.

Anatomy

  1. Code--text-display at 96px, black weight, middle digit in --color-brand; aria-hidden.
  2. TitleThe page heading (h1 in the product).
  3. TextWhat happened and what is safe.
  4. Reference (500).ref, mono caption, for support.
  5. ActionsOne primary recovery action, optional secondary.

Responsive behaviour

  • Left-aligned in the content column at every width (not centred), max 32rem, matching the page header.
  • Below 640px the title wraps under the 96px code; keep titles to four words so the first action stays above the fold at 360×640.
  • Actions wrap; the primary stays first.

Theming

The code is --color-fg-default with the red accent from --color-brand, which stays signal red in both themes (3.3:1 on the dark canvas, used at display size only).

Accessibility

Role and pattern

The page keeps its landmarks; the error replaces <main> content. The title is the page's only h1 and the document <title> starts with it (Page not found — 12L). The big code is aria-hidden because the title says the same thing.

Content

  • Titles in plain words: Page not found, You can’t open this, Something went wrong, You’re offline.
  • Say what is safe: Your data is safe., Orders and payments are safe.
  • Maintenance gives the time back in ET: Back at 3:00 AM ET.
  • Never blame the member, never show a stack trace.
